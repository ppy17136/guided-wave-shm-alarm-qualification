# P11-A 健康侧校准可信度机制探索协议 v1

## 1. 定位与防止结论污染

P10 的损伤测试结果已经被查看，且 P11-A 的提出直接受到“AUROC = 1 但固定阈值召回率低”这一结果启发。因此 P11-A 是 **事后机制探索**，不是确认性试验。任何改善均不得回写为 P10 通过，也不得作为风机叶片密封数据上的最终结论。

本阶段只回答一个问题：在不使用损伤标签选择阈值或规则的前提下，健康校准分数本身能否提示“经验 95% 分位阈值受尾部尖峰支配，不适合给出高置信部署报警”？

## 2. 输入冻结

- 使用 P10 已导出的样本级分数，不重新选择空间窗、通道或 PCA 维数；
- 主分数：`robust_residual_top3`；
- 次分数：`pca_reconstruction`；
- 阴性对照：`raw_input_energy_negative_control`；
- 仅健康校准块用于阈值和可信度规则；健康测试与损伤测试只在规则计算完成后评价；
- 校准样本按文件号排序，固定分成 8 个连续块，每块 5 个文件。

## 3. 阈值候选

### T0：P10 原始阈值

健康校准分数的 95% 分位，采用 `higher` 定义。这是基准，不改变 P10。

### T1：Hampel-6 稳健阈值

记健康校准分数中位数为 \(m\)，MAD 为 \(\mathrm{median}(|s_i-m|)\)，稳健尺度为 \(1.4826\,\mathrm{MAD}\)。定义

\[
T_1=m+6\times 1.4826\,\mathrm{MAD}.
\]

常数 6 固定，不根据损伤召回选择。T1 只作为探索性报警阈值，不替代 P10 主阈值。

### T2：截尾分位阈值

先把校准分数上截到 \(m+3\times1.4826\,\mathrm{MAD}\)，再计算截尾分数的 95% `higher` 分位。它用于检验少数尾部尖峰的影响，不作为最终首选。

## 4. 健康侧校准可信度指标

对每个 5 文件块计算块最大值、块中位数。定义：

1. **尾部块异质性**：最大块最大值 / 块最大值中位数；
2. **阈值影响范围**：依次删除一个块后重算 T0，报告最大值、最小值及相对范围；
3. **尾部支持块数**：全校准前 5% 尾部样本来自多少个块；
4. **稳健阈值分歧**：T0/T1。

预声明“经验分位阈值可信”必须同时满足：

- 尾部块异质性 ≤ 2.0；
- 删除一块后的 T0 相对范围 ≤ 0.5；
- T0/T1 位于 [0.5, 2.0]；
- 校准样本数至少 40，且 8 个块完整。

任一条件失败，则系统输出 `CALIBRATION_UNRELIABLE`。这不是损伤报警，而是拒绝把 T0 当作可部署阈值。

## 5. 探索性评价

规则冻结后，在健康测试和损伤测试上报告：

- T0、T1、T2 的健康测试 FPR；
- 损伤召回率和最早 5 个损伤召回率；
- 连续 3 个样本中至少 2 个超阈值的序列报警结果；
- 各阈值与健康测试最大值、损伤最小值的位置关系；
- 校准可信度是否在看到测试结果之前给出拒判。

这些数值用于机制解释，不用于选择最终风机方法。

## 6. 成功标准

P11-A 不以损伤召回提高作为成功标准。机制成功定义为：

1. 至少一种结构分数被健康侧规则标记为 `CALIBRATION_UNRELIABLE`；
2. 触发原因与 P10 观察到的校准尾部尖峰一致；
3. 阴性对照不会虚假显示与结构分数完全相同的模式，或差异得到明确解释；
4. 输出明确区分“拒绝阈值”“异常排名”和“损伤报警”。

## 7. 对风机密封确认的约束

P11-A 完成后仍不得立即启封风机数据。必须先取得并阅读数据论文全文，基于公开实验程序另行冻结 P11-B：数据阶段、静态/动态主次终点、基线、温度处理、通道聚合、阈值、校准可信度门、失败判据和启封日志。P11-A 中表现最好的事后阈值不得自动成为 P11-B 主阈值。
