# P12-COPV 执行修订 A3：缺失支持元数据的预注册拒判落实

## 1. 触发与结果盲态

任务 `20087.master` 已完成GPU冒烟并生成141个逐H5缓存，随后在读取不可逆损伤T37、50 bar降压H5的
`MetaData/Pressure` 时因键不存在而停止。异常发生在该目标H5读取任何波形数值、计算分数或报警之前；
现有缓存只用于断点续跑，本修订未读取其中的分数或损伤表现。

## 2. 官方清单全面审计

对LOCK1阶段已经读取并冻结的18个官方 `H5_FILES_INFO.json` 重新查询数据集路径，发现：

- 不可逆损伤T37的30个H5均同时缺少 `MetaData/Pressure` 与 `MetaData/Temp_Surface`；
- 不可逆损伤T55另有2个H5同时缺少上述两个字段；
- 总计32个H5；
- 未重新读取ZIP波形，也未用文件名或名义压力替代H5内部支持特征。

## 3. 原协议依据

预注册第3.3节已明确：关键H5元数据缺失或非有限时，样本直接标记
`unsupported/invalid`，不得插值。A3不改变科学规则，只把原先导致执行器异常退出的情况落实为可审计拒判记录。

## 4. 冻结执行行为

1. 仅捕获 `MetaData/Pressure` 或 `MetaData/Temp_Surface` 缺失/非有限；
2. 写入 `invalid_missing_support_metadata`，不读取该H5波形、不计算异常分数；
3. 该工况不作阳性或阴性预测，融合输出为 `abstain_support`；
4. 工况仍保留在损伤支持覆盖率及温度覆盖率的分母中；
5. 通道、频率、采样率、H5结构或波形计算的其他错误继续立即停止；
6. 阈值、支持模型、频率融合、PASS门槛及其余协议均不改变；
7. 已生成的141个冻结特征缓存原样复用，不重算、不筛选。

## 5. PBS服务异常

2026-08-13检查时 `qstat` 返回 `Connection refused`，说明管理节点PBS服务器独立异常。
在PBS管理员恢复服务前不重新提交；服务恢复后使用LOCK2.2脚本断点续跑。
