# P8 探索报告：长期导波监测中的异常方向反转与状态迁移

日期：2026-08-11  
状态：在P7两项确认终点失败后设计的探索分析；不能替代P7确认结论。

## 1. 科学问题的重新定义

P7表明，长期导波监测的主要困难不是某一个模型在随机划分上的分类精度不足，而是：

> 同一类异常分数在不同累积损伤阶段可能升高、降低或被环境漂移提前触发，导致固定方向、固定参考分布和固定报警规则无法长期迁移。

P8首先回答两个问题：

1. 64个冻结候选表示中是否仍包含损伤相关信号？
2. 如果同时检测分数上升和下降，能否恢复低误报条件下的稳定报警？

## 2. 64候选方向稳定性审计

分析使用五随机种子集成后的64个候选分数，对D6→D7至D12→D13七个事件计算逐事件AUROC。所有候选排序、逐事件方向选择和留一事件选择均使用了D7–D13标签，因此全部属于事后探索。

事后七事件宏AUROC最高的候选为：

`input_amplitude_high_max__high`

- 最差事件AUROC：0.3242；

### 2.2 方向无关的可分信号

这说明深度表征和路径重构中存在较强的事件可分信号，但没有一个不依赖事件标签的稳定方向映射。

### 2.3 留一事件选择失败

对每个被留出事件，只用其他六个事件选择候选和方向，再应用到被留出事件：

- 被留出事件宏AUROC：0.2981；
- 最差被留出AUROC：0.0105；
- 仅2/7个被留出事件AUROC大于0.5；
- 七次选择涉及4个不同候选。

典型例子是D7→D8：其他六事件选择了“低分表示损伤”的方向，但D7→D8实际为强烈高分变化，应用该方向后AUROC由0.9895变为0.0105。

因此，事后高方向无关AUROC主要反映“有信号但方向不可迁移”，不能转换为可部署性能。

## 3. 双尾顺序报警实验

为直接检验方向反转，保留P5b全部运行常数：

- 慢窗1024；
- 更新步长32；
- κ=4；
- 阈值8；
- 衰减0.95；
- guard p=0.05。

唯一概念变化是把单侧经验p值改为双尾经验p值，使分数显著升高或降低都能积累证据。筛选64个候选后的事后最佳候选仍为 `input_amplitude_high_max__high`。

结果：

| 指标 | P7单尾锁定结果 | P8双尾事后最佳 |
|---|---:|---:|
| K3检出事件数 | 4/7 | 7/7 |
| K3事件前误报运行总数 | 15 | 10 |
| 最差事件前FPR | 0.0806 | 0.4978 |
| 中位事件后召回 | 0.0048 | 0.1551 |
| 中位K3延迟 | 64.51 h | 33.47 h |

双尾方法明显提高了事件覆盖率和召回，却在后期阶段产生持续报警：

- D10→D11事件前FPR：0.2880；
- D11→D12事件前FPR：0.2811；
- D12→D13事件前FPR：0.4978。

虽然误报“运行数”只有10次，但一次持续数天的报警会造成很高FPR。这说明只统计报警段数量会掩盖长期持续误报，未来必须同时报告FPR、报警运行数和报警持续时间。

64个双尾候选中没有任何一个满足全部P7式运行要求。留一事件候选选择仍检出7/7事件，但最差被留出事件前FPR为0.4954，问题没有通过候选选择解决。

## 4. 机制解释

现有结果支持以下分解：

1. **损伤信号存在**：路径重构和输入幅值候选在逐事件方向无关评价中具有较高可分性。
2. **方向随阶段变化**：早期事件多表现为重构误差或路径差异增大，后期事件则可能表现为降低。
3. **环境或耦合状态持续迁移**：双尾检测在后期事件发生前已长时间报警，说明慢参考不再代表当前健康/既有损伤状态。
4. **输入幅值候选的优势需谨慎解释**：其可能主要反映温度、耦合、激励或增益变化，而非纯损伤，因此不能仅因检出率高就作为最终损伤指标。
5. **稳定性—可塑性冲突**：冻结慢参考可以保留突变，但会把长期环境漂移当作异常；快速适应又可能把真实损伤吸收到新基线。

## 5. P8方法路线：共同模态与局部损伤模态分解

不建议继续单纯筛选64个标量候选。下一阶段应利用8条路径和7个环境变量的结构信息，建立两层模型。

### 5.1 环境共同模态

温度、湿度、激励强度和耦合变化通常会同时影响多条传播路径。可对每个时间点的8路径向量建立：

- 路径共同位置项，如中位数或第一主成分；
- 环境条件化预测项，如稳健回归、核回归或小型状态空间网络；
- 传感器增益/输入幅值共同尺度项。

共同模态主要用于解释和更新环境状态，不直接作为损伤报警分数。

### 5.2 局部路径损伤模态

在去除共同模态后，使用：

- 中心化对数比或路径间对数比；
- 路径排序变化和秩相关距离；
- 路径协方差/图结构残差；
- 局部路径尾部不对称性；
- 快慢窗之间的对称分布距离，如Wasserstein、energy distance或核MMD。

这些统计不要求预先知道异常是升高还是降低，并能抑制所有路径同步变化造成的误报。

### 5.3 状态条件化参考库

用环境共同模态建立多个参考状态，而不是一个无限期冻结的慢窗：

- 按环境状态检索相似历史参考；
- 对参考状态设置时间衰减和覆盖诊断；
- 当当前状态超出参考支持域时输出“状态未知”，而不是直接输出“损伤”；
- 损伤报警只由去共同模态后的局部路径变化触发。

## 6. 评价设计

P8在本数据上的评价只能称为探索或内部验证，建议采用：

1. 严格滚动起点：任何时刻只能使用此前数据建立参考；
2. 事件级外层留一或滚动测试，内层只在更早事件选择参数；
3. 同时报告AUROC、块自助置信区间、最差事件FPR、报警运行数、报警持续时间、召回和检出延迟；
4. 环境负对照：环境状态变化不应被直接计为损伤成功；
5. 消融：共同模态去除、状态参考库、局部路径统计和顺序检测分别验证；
6. 新方法最终需要另一个未见结构、时间段或公开导波数据集进行确认。

## 8. 限定环境状态参考库试验及停止决定

随后执行了一个预先限定边界的机制试验：仅使用 `K=4/8/16` 三种环境状态数、三类冻结路径分量和 `mean/top2/max` 三种局部聚合，共30个候选。每个事件的环境聚类和路径参考统计只在该事件训练窗拟合。

结果：

- 事后固定高分方向最优候选：`input_amplitude__regime_k16__local_top2`；
- 七事件宏AUROC：0.5946；
- 最差事件AUROC：0.3909；
- 5/7事件AUROC大于0.5；
- 留一事件宏AUROC：0.3690；
- 留一事件最差AUROC：0.2262；
- 0/7个被留出事件AUROC大于0.5。

预定停止规则为“若留一事件宏AUROC仍低于0.5，则停止环境状态库分支”。该分支未通过，因此不再扩大K值、不更换聚类算法、不基于D7–D13继续调环境状态库。该结果说明仅按环境变量聚类检索参考，仍不足以解决损伤阶段与历史状态造成的方向迁移。

## 9. P8-B 动态路径图试验及最终停止决定

在上述结果基础上，按 `P8_dynamic_path_graph_protocol_v1.md` 预先固定并执行了动态路径图试验。该试验不再从64个候选中事后挑选，而是固定使用28条传播路径、共同模态去除、环境条件化、快窗128、慢窗2048、步长32、收缩系数0.25和校准分位数0.999；主分数为形状分支与幅值分支的等权融合。附加的输入幅值负对照只用于判断模型是否仍主要跟踪环境或耦合变化。

固定主分支结果如下：

| 指标 | 结果 |

| 七事件宏AUROC | 0.3946 |
| 最差事件AUROC | 0.0202 |
| AUROC大于0.5的事件 | 2/7 |
| Energy-distance宏AUROC | 0.4820 |
| 24 h块自助均值 | 0.3935 |
| 24 h块自助单侧下界 | 0.3485 |
| 最差事件前FPR | 0.6458 |
| 事件前FPR中位数 | 0.0950 |
| 事件前K3误报运行数 | 31 |
| 事件前累计报警时长 | 190.96 h |
| 最长事件前连续报警 | 49.28 h |
| 检出事件数 | 4/7 |

| 事件前未知状态率（最差） | 0.3879 |

四个固定分支的宏AUROC分别为：形状分支0.4475、幅值分支0.3894、输入幅值负向对照0.4930、固定融合主分支0.3946。六项内部继续门槛全部未通过。尤其是输入幅值负对照优于三个所谓损伤分支，说明现有P7潜变量及其图残差仍主要反映环境、激励和耦合状态，而没有形成可跨累积损伤阶段迁移的损伤坐标。

因此作出以下正式停止决定：

1. 停止在P7冻结潜变量上继续增加图模型复杂度；
2. 不在D7—D13上调整快慢窗、核特征数、岭参数、阈值、融合权重或未知状态边界；
3. P8-B保留为严格的否定性机制证据，不以事后最佳分支替代固定主结果；
4. 下一阶段回到原始波形和传播物理，研究温度引起的时移/伸缩、频散、幅相共同变化与路径几何约束；
5. 新方法先在公开的温度控制数据上开发，再在另一结构上做冻结外部确认。

该停止决定并不表示长时导波损伤监测不可行，而是说明“基于当前掩码重构潜变量的复杂后处理”已经到达证据边界。继续提高后处理复杂度会增加研究者自由度，却没有独立数据支持。
