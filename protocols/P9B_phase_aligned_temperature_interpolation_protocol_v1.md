# P9B 相位伸缩对齐温度插值协议 v1

日期：2026-08-11  
状态：在运行P9B前冻结  
性质：P9A健康FPR未通过后的单一物理机制修正

## 1. 触发依据

P9A固定二次插值在四任务上获得宏AUROC 0.8312、最差任务AUROC 0.7010，健康重构误差较最近锚点降低62.49%，且四任务方向一致并优于输入RMS负对照；但最差温度FPR为15%，未达到10%门槛。误差主要集中在50 kHz的0/5 ℃和35/40 ℃，符合“温度相位漂移并非逐采样点低阶幅值函数”的解释。

本分支只检验一个机制：先以时间轴伸缩将四个健康锚点对齐到共同相位坐标，再在共同坐标内做同样的二次温度插值。

## 2. 固定数据与切分

- 四个健康锚点：`{-10, 10, 30, 50} ℃`；
- 相位参考锚点：`30 ℃`；
- 九个留出温度：`{-5, 0, 5, 15, 20, 25, 35, 40, 45} ℃`；
- 所有伸缩因子只用Baseline四锚点估计；
- Diagnostic波形不得参与伸缩、插值、阈值或参数范围选择；
- 主结果保留I2-45 ℃完全重复记录；排除I2-45 ℃只作为已登记的语义缺失敏感性分析。

## 3. 固定算法

对每个任务和每条路径独立执行：

1. 将每条波形减去前256点中位数；
2. 以30 ℃Baseline为参考；
3. 对其余三个锚点，在`[0.99, 1.01]`的81点均匀网格搜索时间轴伸缩因子；
4. 以全6000点去均值归一化相关系数最大为唯一选择准则；
5. 30 ℃锚点因子固定为1；
6. 将四锚点按各自因子伸缩到共同相位坐标；
7. 对对齐后的每个采样点按温度做二次最小二乘插值；
8. 对四个伸缩因子同样做二次温度插值，得到目标温度因子；
9. 将共同坐标中的预测波形按目标因子的倒数变换回目标温度坐标；
10. 超出原时间域的插值点置零，统一使用线性插值。

不搜索参考温度、不改变伸缩范围或网格数、不选择局部波包窗、不对Diagnostic单独拟合伸缩或增益。

## 4. 主分数与对照

主分数仍为归一化残差能量：

`mean((query-reference)^2) / mean(reference^2)`

直接与P9A逐采样点二次插值比较。P9A最近锚点、OBS、同温度Oracle和原始RMS结果保持不变，不重新选择。

## 5. 固定通过条件

P9B进入后续小型学习残差模型前应满足：

1. 健康平均重构误差低于P9A二次插值；
2. 四任务宏AUROC不低于0.70且最差任务不低于0.60；
3. 四任务效应方向均为正；
4. 固定健康95%阈值下最差温度FPR不高于10%；
5. 主结果与I2-45 ℃敏感性结果均完整报告；
6. 估计伸缩因子不集中在0.99或1.01边界；若大量触边，则判定预设模型不充分而不是扩大搜索范围。

若仍未通过FPR门槛，停止继续微调伸缩网格；下一步只能登记新的频带相位模型或分温度保序校准方案。
