# P9C 频带幅相温度模型协议 v1

日期：2026-08-11  
状态：在运行P9C前冻结  
性质：P9B单一全波形伸缩大量触边后的频散机制检验

## 1. 触发依据

P9B相位对齐二次插值将四任务宏AUROC由0.8312提高到0.8941，最差任务达到0.8545，但最差温度FPR仍为15%，且59.17%的非参考锚点伸缩因子落在预设0.99/1.01边界。根据P9B停止规则，不扩大伸缩范围和网格，而改检验“温度效应随频率变化，不能用单一时间伸缩表示”的机制。

## 2. 固定输入与频带

- 数据、四锚点、九个留出温度、增量损伤定义与P9A/P9B完全相同；
- 40 kHz任务固定使用20–60 kHz频带；
- 50 kHz任务固定使用25–75 kHz频带；
- 对每条6000点、12 MHz波形先减去前256点中位数，再计算实数FFT；
- Baseline和Diagnostic使用完全相同的固定频带；
- 不根据损伤结果改变频带、窗函数、FFT长度或幅值门槛。

## 3. 固定幅相插值

对每个任务、每条路径和每个频带内FFT频点：

1. 从四个Baseline锚点取得复频谱；
2. 对`log(|X| + 10^-12)`沿温度做二次最小二乘；
3. 对复频谱相位按温度顺序展开后做二次最小二乘；
4. 在每个留出温度预测对数幅值和相位并组合为复频谱；
5. 频带外频点置零，通过实数逆FFT得到预测基线；
6. 对Baseline伪诊断和Diagnostic查询也先保留同一固定频带再计算残差。

模型只用Baseline四锚点；Diagnostic不得参与相位展开、插值、尺度或阈值形成。

## 4. 主分数和门槛

主分数仍为频带波形上的归一化残差能量。固定门槛：

1. 四任务宏AUROC不低于P9B的0.8941；
2. 最差任务AUROC不低于0.80；
3. 四任务方向均为正；
4. 固定健康95%阈值下最差温度FPR不高于10%；
5. I2-45 ℃重复记录保留为主结果，另报排除敏感性；
6. 若未同时改善AUROC与FPR，则停止本频带幅相分支，不搜索其他频带。

P9C仍是开发结果；即使通过，也不能解封风力机叶片最终确认集。后续还需OGW或另一开发集上的一次迁移检查以及正式确认注册。
