# P9D 温度条件化健康阈值协议 v1

日期：2026-08-11  
状态：在运行P9D前冻结  
性质：P9B分数固定后的健康异方差校准

## 1. 唯一目标

P9B主分数冻结为`phase_aligned_quadratic`归一化残差能量，不再改变波形表示、伸缩网格、参考温度或损伤方向。P9D只检验统一阈值的15%最差温度FPR是否可由不使用Diagnostic的温度条件化健康阈值降低。

## 2. 固定交叉拟合

对每个任务分别执行九折留一温度交叉拟合：

1. 被留出的一个温度既不参与分位数计算，也不参与温度曲线拟合；
2. 在其余八个温度，分别计算40条Baseline路径P9B分数的经验95%分位数，分位数方法固定为`higher`；
3. 对八个`log(q95 + 10^-12)`与温度做二次最小二乘；
4. 在被留出温度预测对数阈值并指数变换；
5. 用该阈值计算被留出温度40条Baseline的FPR和40条Diagnostic的召回；
6. 九个温度轮流留出，汇总四个任务。

Diagnostic分数不得参与阈值、曲线阶数、变换或任何参数选择。

## 3. 主结果和敏感性

- 主结果保留I2-45 ℃精确重复的Diagnostic记录；
- I2-45 ℃只影响召回，不影响健康阈值与FPR；
- 另报排除I2-45 ℃的召回敏感性；
- AUROC不因阈值改变，继续引用P9B主AUROC 0.8941，不得把校准包装成区分性能提升。

## 4. 固定通过条件

1. 四任务中每个温度的Baseline FPR均不高于10%；
2. 四任务汇总的平均召回不低于P9B统一阈值召回0.6896减0.10，即不低于0.5896；
3. 每个任务平均召回不低于其P9B统一阈值结果减0.15；
4. 预测阈值均为有限正数；
5. 不得根据结果改成一次、三次、样条或分段模型。

若未通过，停止在LambNet-T上继续调整阈值函数；下一步转向第二数据集或承认需要更多独立健康重复来估计条件尾部。
