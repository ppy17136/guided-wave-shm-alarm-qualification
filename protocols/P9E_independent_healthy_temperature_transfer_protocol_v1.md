# P9E 独立健康变温迁移协议 v1

日期：2026-08-11  
状态：在运行P9E前冻结  
数据：Zenodo 10.5281/zenodo.19209079，CC BY 4.0

## 1. 角色与限制

该数据来自另一块无损伤CFRP板，采用1个Ondulys激励源和44个线性接收位置，100 kHz Ricker激励、2 MHz采样、20–70 ℃变温、每5分钟采集。它只用于检验独立结构上的健康温度重构、误报和支持域，不包含损伤，不能计算损伤AUROC或召回。

220个SG2中前219个可按官方MATLAB脚本映射气候记录；最后一个气候元数据缺失，不进入温度模型评价。

## 2. 固定锚点选择

名义锚点固定为`{20, 35, 50, 65} ℃`。对每个名义锚点：

1. 只考虑气候程序温度等于该锚点的采集；
2. 按时间排序后选择该平台的中央一条；
3. 模型使用其实际测得温度，不把名义温度替代测量温度；
4. 选定后不得根据波形质量或结果更换。

50 ℃锚点作为P9B相位参考，对应P9B四锚点中的第三个参考位置。

## 3. 固定P9B迁移

- 每条波形减去前85点中位数；85约为P9B前256/6000的相同比例；
- 对每个接收位置独立估计四锚点到50 ℃参考的时间伸缩；
- 伸缩网格原样固定为0.99–1.01、81点；
- 全2000点去均值归一化相关最大为选择准则；
- 锚点进入共同相位坐标后，对波形和伸缩因子按实际温度做二次插值；
- 查询采集不得单独拟合伸缩、增益或阈值；
- 主分数为归一化残差能量。

## 4. 支持域与评价

- 主插值支持域为四个实际锚点温度的最小值至最大值；
- 支持域外温度只报告为外推/未知，不并入主FPR；
- 四个锚点自身不并入评价；
- 温度分箱固定为最接近的5 ℃，仅报告至少包含5次采集的箱；
- 同时报告接收位置级FPR和“任一接收位置报警”的采集级报警率；后者不作为主要门槛。

## 5. 固定阈值

主阈值直接迁移LambNet-T P9B四任务健康95%阈值中的最大值：

`0.02609810031847493`

选择最大值是事前固定的保守跨任务规则，不能用本数据修改。

另作次要的时间外推校准诊断：按时间排序后，用支持域内非锚点采集的前30%形成经验95%阈值，在后70%测试。该诊断不得替代直接迁移主结果。

## 6. 通过条件

1. 直接迁移阈值下支持域内接收位置总体FPR不高于5%；
2. 至少5次采集的每个5 ℃温度箱FPR不高于10%；
3. 非参考锚点伸缩因子触及0.99/1.01边界的比例低于10%；
4. 结果不依赖删除任一接收位置；
5. 所有超出支持域的采集均明确标记，不作为健康成功样本。

若未通过，不在本数据上改变锚点、阈值、伸缩范围或温度箱；结果用于判断P9B跨结构迁移边界。
