# P9 原始波形物理建模与外部验证数据协议 v1

日期：2026-08-11

## 1. 转向依据

P7的两个确认终点均失败；P8的方向稳定性、双尾顺序检测、共同/局部模态、有限环境状态库及动态路径图均未获得可迁移的低误报结果。P8-B固定主分支宏AUROC为0.3946，输入幅值负对照为0.4930，说明在P7潜变量上继续增加后处理复杂度缺乏依据。

P9不再以P7重构潜变量为主输入，而回到原始导波波形及传播物理，重点分解：

1. 温度引起的到达时刻漂移和时间轴伸缩；
2. 激励、耦合和增益引起的近似共同幅值变化；
3. 频散导致的频带相关相位与包络变化；
4. 局部损伤对部分传播路径造成的非共同散射、衰减和波包形状变化；
5. 未被训练温度、载荷或运行状态覆盖时的分布外识别。

## 2. 数据集分工与信息隔离

### 2.1 开发集A：LambNet-T

- 数据页：https://data.mendeley.com/datasets/d9pzsm33gy/1
- DOI：10.17632/d9pzsm33gy.1
- 用途：温度补偿、跨温度表征、损伤方向稳定性和原始波形预处理开发。
- 已知元数据：13个温度水平（-10 ℃至50 ℃、步长5 ℃）、两个冲击位置、40/50 kHz、多传播路径、每条记录6000个采样点。
- 允许操作：完整解析、可视化、开发/验证划分、消融和参数选择。

### 2.2 开发集B：Open Guided Waves温度数据

- 官方下载页：https://openguidedwaves.de/downloads/
- 平台论文：https://elib.dlr.de/123726/
- 温度数据集合：https://doi.org/10.6084/m9.figshare.c.4488089.v1
- 用途：检验在LambNet-T上形成的温度校正能否迁移到另一块复合材料板；允许做有限的二级开发，但所有改动必须记录。

### 2.3 补充机理集：Open Guided Waves受控损伤及数值数据

- OGW #1：CFRP板、12个压电传感器、可逆模拟损伤，用于路径几何、损伤定位和可解释图结构。
- SFEM数值数据：https://zenodo.org/records/13844147
- 用途：物理一致性、预训练或敏感性分析；不能替代真实结构外部确认。

### 2.4 最终封存确认集：风力机叶片疲劳导波数据

- 官方数据：https://zenodo.org/records/13692213
- DOI：10.5281/zenodo.13692213
- 已知元数据：真实风力机叶片、循环疲劳直至失效、5个PZT、静态与动态采集并包含温度信息。
- 角色：唯一最终外部确认集。
- 封存规则：可以下载原始字节、记录文件名/大小/散列值，但在P9方法、特征、训练策略、阈值和主要终点冻结前，不得解压、读取波形、绘图、查看标签时序或根据该数据调整任何选择。

## 3. P9方法开发的预定边界

第一阶段仅允许下列物理模块；每一模块都必须保留关闭状态作为消融对照：

1. 基于互相关或解析包络的传播时延校正；
2. 基于基线信号伸缩的温度补偿；
3. 分频带幅相归一化，而非整条波形单一幅值归一化；
4. 传感器/路径共同因子与局部残差分解；
5. 由传感器几何定义的固定路径图，不从确认标签学习图边；
6. 对称双向变化统计，但阈值只由健康开发数据确定；
7. 明确的分布外输出：支持不足时报告“未知”，不得直接判为损伤。

暂不允许：

- 在同一外部测试集上遍历大量网络、损失或阈值并报告最佳值；
- 根据事件标签逐事件翻转损伤方向；
- 把模拟数据与真实数据随机混合后声称外部泛化；
- 用最终风力机叶片确认集选择任何超参数。

## 4. 数据切分与选择规则

### 4.1 LambNet-T

至少采用两种切分：

1. 留温度区间外推：训练使用中间温度，测试包含低温和高温端点；
2. 留冲击位置外推：一个冲击位置用于开发，另一位置用于测试或反向交叉。

任何标准化、时间校正模板和阈值只能在训练侧拟合。以路径或重复测量为单位分组，禁止同一物理记录的裁剪片段跨越训练和测试。

### 4.2 OGW温度数据

先按LambNet-T冻结一个候选方法；OGW仅允许一次主评估。若因格式或传感器拓扑必须修改，只允许数据接口与几何映射修改，不得查看标签后改变分数定义。若发生方法性修改，则OGW降级为开发集并重新登记。

### 4.3 风力机叶片最终确认

在解封前另行形成P9确认注册文件，至少冻结：

- 代码提交或文件SHA256；
- 数据散列和纳入排除规则；
- 唯一主分数及方向；
- 健康参考期和阈值形成规则；
- 主要事件或失效时间定义；
- 主要区分终点和顺序报警终点；
- 置信区间、缺失数据和异常传感器处理；
- 通过/失败标准。

## 5. 开发阶段评价指标

不以单一AUROC作为目标。至少同时报告：

- 逐温度、逐路径、逐损伤位置AUROC及宏平均；
- 最差温度/最差路径性能；
- 健康跨温度FPR；
- 固定健康阈值下的召回；
- 可靠性或经验分位数校准；
- 未知状态率；
- 方向稳定性：各温度和结构中损伤效应符号是否一致；
- 物理消融：时间校正、频带校正、共同因子和图约束分别贡献多少；
- 多随机种子或确定性重复性；
- 分组自助置信区间，分组单位必须对应物理试验重复而非单个采样点。

## 6. 阶段门槛

进入最终外部确认前，候选方法应同时满足：

1. LambNet-T留温度和留损伤位置测试均优于预定传统基线；
2. OGW温度数据上不经标签调参仍保持同方向且宏AUROC高于0.65；
3. 健康跨温度最差FPR不高于10%；
4. 至少一个局部损伤残差分数明显优于输入幅值/温度负对照；
5. 主要结论在消融、随机种子和分组自助分析下稳定；
6. 代码、环境、数据清单和全部失败试验可审计。

若未满足，不解封风力机叶片数据；继续结果只能作为开发研究报告。

## 7. 论文定位

若P9门槛通过，论文可定位为：

> 面向跨温度、跨结构和长期运行环境的物理约束导波损伤表征，以严格的时间/结构外推和完全封存的真实叶片疲劳数据进行确认。

P7/P8应作为研究动机和严谨负结果：它们证明随机划分或单结构事后最优不足以说明长期部署能力，也为P9的原始波形物理补偿、负对照和封存确认设计提供直接依据。
